# Эконометрический анализ рынка e-commerce в России, 2006-2023

Курсовая работа по эконометрике: от чего зависит объем рынка электронной коммерции.

## Данные
18 лет наблюдений (2006-2023):
- **Y** - объем рынка e-commerce, млрд руб.;
- **X1** - инвестиции в основной капитал на цифровизацию;
- **X2** - доля безналичных платежей, %;
- **X3** - пользователи интернета на 100 человек.

## Что сделано
1. **Корреляционный анализ:** сильнее всего с рынком связаны инвестиции в цифровизацию (r = 0,93) и доля безналичных платежей (r = 0,86); между X2 и X3 высокая корреляция (0,92), то есть риск мультиколлинеарности.
2. **Регрессия:** парные модели и пошаговая множественная регрессия; лучшая модель — X1, X2 и взаимодействие X2·X3. Модель с X1: R² = 0,86, F-статистика значима (p < 0,001).
3. **Проверка предпосылок МНК:** случайность остатков, нулевое среднее, отсутствие автокорреляции и нормальность подтверждены; гомоскедастичность не выполняется, поэтому МНК применим с ограничениями.
4. **Временной ряд:** мультипликативная модель, скользящая средняя, сезонная компонента, ранговый коэффициент Спирмена для проверки тренда.
